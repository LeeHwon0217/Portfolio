// 01 · problem

파일 탐색기 검색의 한계

파일 이름과 위치를 정확히 기억해야만 찾을 수 있고, 이미지·영상·음악의 "내용"은 검색 사각지대입니다. DB_Insight는 기억나는 내용만으로 5개 도메인을 한 번에 검색합니다.

기존 한계설명
파일명 의존"계약서_최종_진짜최종.docx" 같은 이름을 정확히 알아야 검색 가능
의미 이해 없음"작년 여름 워크샵 발표자료" 같은 자연어 문장으로 검색 불가
멀티미디어 사각지대이미지·영상·음악은 내용 검색이 전혀 안 됨
비정형 파일스캔 PDF·이미지 속 텍스트는 완전한 사각지대

🔎 의미 기반 검색

"파란 하늘 사진", "예산 얘기 나온 영상" 같은 자연어로 검색합니다.

🔒 완전 로컬 동작

인터넷 불필요. 파일이 외부로 전송되지 않습니다.

📦 단일 EXE 배포

Electron + Flask를 묶어 설치 없이 포터블 exe 하나로 실행합니다.

// 02 · tri-chef fusion

3축 임베딩 · 복소 에르미트 결합

같은 파일을 세 모델로 각각 임베딩한 뒤, 세 축의 코사인 유사도를 별도 학습 없이 하나의 수식으로 결합합니다. 한 모델이 점수를 독점하지 못해 찾으려는 파일을 더 정확히 가려냅니다.

시각 축 · Real

SigLIP2

이미지·프레임의 시각적 내용을 인코딩.

언어 축 · Imag

BGE-M3

텍스트·캡션·STT를 인코딩 (+ 스파스).

구조 축 · Z

DINOv2

이미지의 구조·형태 특징을 인코딩.

Query → SigLIP2 + BGE-M3 + DINOv2 → Complex Hermitian Fusion → 유사도 점수

📐 도메인별 절대 임계값 + 드리프트 가드

무작위 비매칭 쌍에서 도메인별 임계값을 학습하고, 증분 인덱싱 중 새 μ_null이 직전 값의 0.5~2배를 벗어나면 거부해 안정성을 지킵니다.

🇰🇷 한국어 특화 + 콘텐츠 주소 캐시

한국어 문자 bigram 어휘 필터로 정밀도를 높이고, SHA-256 콘텐츠 주소 캐시로 중복 임베딩을 방지합니다.

// 03 · domains

5개 도메인, 하나의 검색창

도메인마다 최적의 인코더로 임베딩한 뒤 Tri-CHEF로 결합합니다. 단, 음악(BGM)은 일부러 융합하지 않았습니다.

도메인파일처리 방식
DocPDF·DOCX·HWP텍스트 청크 분할 → BGE-M3 + 스파스 인덱스
ImgJPG·PNG·WEBPSigLIP2 + BLIP/Qwen 캡션 → BGE-M3
MovieMP4·MKV·AVI장면 프레임 → SigLIP2 + Whisper STT
RecMP3·WAV (음성)Whisper STT → BGE-M3
BGMMP3·FLAC (음악)Chromaprint + CLAP + librosa (비융합)

💡 설계 인사이트 — "언제 융합하지 말아야 하는가"

음악은 의미축이 다른 도메인과 겹치지 않아, Tri-CHEF 융합 대신 CLAP + Chromaprint를 의도적으로 분리해 처리했습니다. 무조건 융합하는 대신 융합이 도움이 될 때와 아닐 때를 구분한 것이 이 프로젝트의 보완적 설계 교훈입니다.

// 04 · aimode

파일에서 '답'을 만드는 RAG 에이전트

검색을 넘어, 로컬 LLM(Ollama)과 대화하며 문서를 읽고 출처가 달린 답을 만듭니다. LangGraph 11개 노드로 구성된 RAG 에이전트입니다.

Q. "DBMS 시장 규모가 얼마야?"
A. "317억 달러입니다 (40페이지)" ← 출처 페이지까지 표시

1

라우팅 · 의도 분석

질문 유형을 분기하고 파일명/내용 키워드를 추출합니다.

2

파일 벡터 검색

ChromaDB에서 관련 파일 후보 Top-K를 추출합니다.

3

실제 내용 정밀 검색

후보 파일을 실제로 읽어 스캔 후 전후 420자 자르기로 관련 구간을 추립니다.

4

인용 추출 · 답변 생성

Ollama LLM이 토큰 단위로 스트리밍 응답하고 [출처N]로 근거를 표시합니다.

🛡 환각 차단

문서와 매칭이 약하면 지어내지 않고 "문서에 없습니다"라고 답하는 신뢰도 게이트.

🔐 데이터 보안

LLM을 Ollama(gemma3) 로컬 구동 — 모든 처리가 로컬, 외부 유출 0.

⚡ 응답 절반

후속 질문은 직전 문서를 재활용해 벡터 검색을 생략, 응답 시간을 절반으로.

성능 (범위를 분리해 표기)
