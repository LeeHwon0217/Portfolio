한국어 뉴스·미디어 영상 60편을 대상으로 시각(CLIP)과 음성(Whisper STT) 신호를 융합 임베딩하여, 텍스트 쿼리만으로 원하는 장면이 담긴 영상을 의미론적으로 찾아냅니다. 10가지 임베딩 방법을 직접 비교 설계하고 k-NN LOO 신뢰도 90.0%를 달성했습니다.

문제 정의

영상은 검색하기 어렵습니다

제목과 태그만으로는 영상 안에서 실제로 무슨 일이 일어나는지 알 수 없습니다. 화면의 장면과 음성 발화를 함께 이해해야 진짜 "내용 기반" 검색이 가능합니다.

👁️

시각 신호

PySceneDetect로 씬을 감지하고 키프레임을 CLIP(512d)으로 임베딩해 화면 내용을 벡터화합니다.

🎙️

음성 신호

faster-whisper로 한국어 STT를 추출하고 형태소·문장 단위로 전처리해 발화 내용을 임베딩합니다.

🔀

융합 검색

두 신호를 가중 결합한 벡터로 쿼리와의 코사인·유클리드 하이브리드 스코어를 계산합니다.

"조진웅 파문" 검색 → "조진웅 소년범 논란" 내용이 담긴 영상 반환
"12월즈음" 검색 → "12월 초부터 한 달은 걸릴 것 같고" 문장이 포함된 영상 히트 (유사도 0.737)
시스템 아키텍처

두 갈래 신호를 하나의 벡터로

시각 경로와 음성 경로가 병렬로 처리된 뒤 가중 융합되어 시각화·지표 계산·검색 서버로 흐릅니다.

실험 설계

10가지 임베딩 방법을 단계적으로 개선

이미지만 쓰는 단순한 방법에서 출발해, 멀티모달 융합 → 가중치 최적화 → 한국어 특화 → 문장 단위 멀티벡터까지 점진적으로 발전시켰습니다.

🧩 STT 청킹 (M7/M8)

350단어 + 50단어 overlap으로 분할 후 문장 임베딩을 평균. 512토큰 제한을 넘는 긴 발화에서 정보 손실을 방지합니다.

🔎 문장 단위 멀티벡터 (M9/M10)

영상 전체 평균이 아닌 문장별 벡터 중 쿼리와 가장 유사한 문장을 선택해, 신호 희석 없이 짧은 단서도 잡아냅니다.

주요 발견

실험에서 얻은 인사이트

01

가중치 최적값

20:80 ~ 80:20 스윕 실험 결과 시각 40% : 음성 60%에서 카테고리 분리가 가장 뚜렷했습니다.

02

형태소 보강 효과

YAKE만으로는 인명·지명 같은 고유명사가 누락 → konlpy 명사 전수 추출 합집합으로 신뢰도 90.0% 달성.

03

문장 단위의 힘

영상 평균 벡터는 "겨울" 같은 짧은 단서를 희석. 문장 단위 검색은 관련 문장을 직접 히트(유사도 0.737)했습니다.

04

한국어 모델 우위

ko-sroberta에서 "겨울"↔"12월" 유사도 0.57로, 다국어 MiniLM(0.35) 대비 63% 향상.
