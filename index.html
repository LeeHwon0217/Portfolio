2026.01 – 02 · 아동 HTP 그림 심리 분석 플랫폼
팀장

부모가 아이의 그림을 올리면 AI가 심리 발달 상태를 해석해 리포트로 돌려주는 서비스.

  • YOLOv8 Instance Segmentation으로 나무·집·사람 그림 요소 감지(최대 18클래스). 심리검사 특성상 누락이 곧 오판이라 confidence를 0.15로 낮춰 민감도를 높였습니다.
  • HTP 논문 4편을 RAG(LangChain + ChromaDB)로 구축하고 Gemini 2.5로 T-Score·발달단계 해석 리포트를 생성했습니다.
  • VARCO-VISION VLM OCR로 그림일기 손글씨를 인식, NF4 4-bit 양자화로 VRAM을 6.8GB → 0.9GB로 절감했습니다.
  • Frontend · Backend · AI · OCR 4개 마이크로서비스를 Docker화하고, AWS EC2 CPU/GPU를 분리 배포해 GPU 비용을 최소화했습니다.

  • 한국어 영상 60편을 CLIP 키프레임(시각) + Whisper STT(음성)로 융합 임베딩해, 화면과 발화 내용을 함께 검색합니다.
  • 10가지 임베딩 방법을 직접 설계·비교해 k-NN LOO 신뢰도 90.0%를 달성하고, 가중치 스윕으로 시각40:음성60 최적 비율을 도출했습니다.

  • Flask 검색 서버 + 코사인/유클리드 하이브리드 스코어 + 3D Plotly 시각화까지 구현했습니다.
